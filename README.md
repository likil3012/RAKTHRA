# 🩸 RAKTHRA
### Connecting Blood. Connecting Lives.

RAKTHRA is a blood donor connection platform designed to connect people who need blood with potential donors. The platform helps users register as donors, search for blood donors, and create emergency blood requests.

## 🎯 Project Objective

The main objective of RAKTHRA is to make blood donation connections easier and faster by providing a platform where blood donors and people in need can connect.

## ✨ Features

- 🔐 User Registration and Login
- 🔑 Email and Password Authentication
- 🔵 Google Sign-In
- 🩸 Donor Registration
- 🧬 Blood Group Selection
- 📍 City-Based Donor Search
- 🚨 Emergency Blood Requests
- 📋 Active Blood Requests
- 🤝 Donor Response System
- 🔥 Firebase Integration
- 📱 Responsive User Interface
